# ui

Svelte driver UI over the herdsman daemon. App bootstrap — scaffolding, the
SvelteKit-vs-Vite/tooling choice, dev launch, and repeatable validation — is unit
F1's first deliverable (see `notes/ui-views.md`); the choice is confirmed with the
owner in that session, not pre-decided here.

This README holds the reusable dev-launch and check commands; units record them
here as they land (F1 establishes the first set). Per-unit design decisions live
in the skill's `.impeccable/surfaces/` briefs.
